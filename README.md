# NexusEng

Projeto desenvolvido no âmbito da unidade curricular de Engenharia de Software. 

Toda a estrutura e lógica da aplicação encontram-se concentradas nos ficheiros (`index.html`, `script.js` e `style.css`), de forma a simplificar a execução e o deploy.

## Como executar

Não é necessário instalar dependências complexas ou configurar um servidor de base de dados:

1. Clona este repositório:
   ```bash
   git clone https://github.com/teu-utilizador/ES.git
   ```
2. Certifica-te de que os três ficheiros principais (`index.html`, `script.js` e `style.css`) estão na mesma pasta.
3. Abre o ficheiro `index.html` diretamente num navegador (Chrome, Firefox, Edge, etc.).

*(Opcional)* Se usares o VS Code, abre a pasta do projeto e utiliza a extensão **Live Server** para executar a aplicação num servidor local e ver as alterações em tempo real.

## Estrutura do repositório

```text
ES/

├── script.js            # Lógica e comportamento (JavaScript)
├── style.css            # Estilos e design (CSS)
```
